## Ground rules (what Claude can't do)
- **Memory:** no memory between sessions. Everything lives in this folder.
- **Your PC:** can't install on it. Gives step-by-step instructions, or uses a folder you connect via Remote Control.
- **Codex:** can't run it. You run it; Claude compares the results.
- **24/7 hosting:** can't do it from here. OpenClaw needs your own VPS.
- **Trading:** no live trades, no personalised investment advice (not SEBI-registered). Backtests and paper trading only.
- **Legal/tax:** research only. A lawyer or CA signs off.
- **Medicines:** no help with controlled drugs (e.g. anabolics) or prescription shipments to individuals where the destination country's law forbids it. Every pharma brief checks the rules country by country.
- **AI video:** Higgsfield generation uses your credits. Claude asks first.
