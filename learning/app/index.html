      Lesson 01 · List 1 item #3

      GitHub, Python & Claude Code on Windows

      Goal: a working toolkit and knowing what each piece does. You won't write code. You'll direct, run and check it.

      1 · Explainer
      TerminalA chat window with your computer. Claude Code, Codex and OpenClaw all run here. On Windows: PowerShell.
      Git“Track changes” for a whole folder. Download projects and undo mistakes.
      GitHubGoogle Drive for Git folders (repos). Your tracker lives there.
      PythonThe language most AI tools use. You need it to run what AI writes for you.
      Claude CodeA senior developer inside your terminal. You describe the outcome; it writes, runs and fixes.
      VS CodeNotepad with superpowers, for looking at files.

      Words you'll hear

      Repo: a project folder tracked by Git
      Clone: download a repo to your PC
      Commit: a saved checkpoint with a message
      Push / Pull: upload / download changes
      Branch: a parallel copy for trying changes
      Library: ready-made code, installed with pip install
      requirements.txt: the shopping list of libraries
      venv: a separate box of libraries per project
      README.md: the manual. Always read it first

      Load any GitHub project

      1. Read the README
      2. git clone <url>, then cd into the folder
      3. python -m venv .venv, then .venv\Scripts\activate
      4. pip install -r requirements.txt
      5. Run what the README says
      6. Stuck? Run claude and say “get this running on my Windows PC and explain each step”

        3 · Mini project: clean a messy leads file

        From the project folder, run claude and paste this prompt. The file sample_leads.csv has 15 fake IndiaMART, TradeIndia, website and WhatsApp inquiries.

        Read sample_leads.csv. Write a Python script clean_leads.py using pandas that:
1. removes fully blank rows,
2. normalises phone numbers to international format, digits only
   (assume India +91 if no country code; drop a leading 0),
3. lowercases emails and title-cases names,
4. treats two rows as the same person if phone OR email matches,
   merges them keeping the earliest date and combining sources,
5. flags junk/test rows and rows with no phone and no email
   into a separate file,
6. saves leads_clean.csv and leads_flagged.csv and prints a summary.
Explain each step in simple language for a non-coder, then run it.
