# Lesson 01: Quiz

Answer in your own words and send the answers to Claude. Claude will review them and explain anything you missed.

1. What's the difference between **Git** and **GitHub**?
2. You find a cool AI project on GitHub. What is the **first file** you read, and what are the usual 4–5 steps to get it running?
3. What does `pip install -r requirements.txt` do?
4. Why do we create a **virtual environment** (`.venv`) for each project?
5. What is a **commit**, and why write a clear message with it?
6. Claude Code says it finished the lead cleaner. How do you know it's actually correct, without reading the code?
7. In your own words: what is a **branch**, and why is our tracker on one?
8. **Scenario:** you run a project and see `ModuleNotFoundError: No module named 'requests'`. What does it mean, and what do you do (or what do you tell Claude Code)?
9. **Business thinking:** name 2 other messy files or data sources at MediSeller that a script like this could clean automatically.
